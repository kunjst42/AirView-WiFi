# AirView alpha

**AirView alpha** — это стильная консольная программа для Windows, которая сочетает в себе реальную диагностику Wi-Fi сетей и глубокую визуальную имитацию хакерского аудита. Написанная на Batch с использованием PowerShell для отрисовки интерфейса, она предоставляет максимум информации о беспроводных сетях, проверяет соединение и развлекает ретро-эстетикой.

> **Важно:** AirView alpha — **не настоящий хакерский инструмент**. Все процессы «взлома» являются визуальной симуляцией, созданной для демонстрации и развлечения. Программа не наносит вреда вашей системе или сетям.

---

## Возможности

- **Два режима работы:**
  - **Utility (Диагностика)** — реальные данные о Wi-Fi сетях через `netsh wlan`, проверка `ping`, вывод ARP-таблицы, анализ каналов и просмотр системных сетевых настроек.
  - **Cracker (Симуляция)** — интерактивная имитация аудита безопасности с перехватом рукопожатий, подбором ключей WEP/WPA2/WPA3/WPS, KRACK и Evil Twin.
- **Интерактивный «взлом»:** Атака идет в реальном времени. Если возникает ошибка (например, срабатывает MAC-фильтр), симуляция встает на паузу, и вам нужно ввести правильную команду исправления (о них можно узнать в `/errors`), чтобы продолжить.
- **Максимум информации о сети:** детальные данные (SSID, BSSID, OUI-вендор, шифрование, WPS, RSSI, канал, частота, дистанция, задержка, MIMO, PMF 802.11w, ширина канала, нагрузка BSS). Команда `/all` выдает абсолютно всё.
- **Анализ системы (`/sysnet`):** Показывает, что может блокировать сеть (брандмауэр, hosts-файл), а также выводит активные DNS, системные прокси и VPN-адаптеры.
- **Проводные сети:** В самом низу списка серым цветом отображаются кабельные подключения (Ethernet) для полноты картины.
- **Ретро-интерфейс:** 8-битные звуки, пиксельный маскот AV, адаптивная вёрстка, поддержка мыши и клавиатуры.
- **Упрощённый режим:** Включается в настройках. Переводит сложные технические термины на понятный человеческий язык для новичков.
- **Мультиязычность:** Английский, русский и китайский языки (включая справку `/help`).

## Установка и запуск

1. Скачайте файл `AirView_alpha_v#.#.#.bat`.
2. **Важно:** Убедитесь, что файл сохранён в кодировке **UTF-8**, иначе интерфейс и кириллица могут сломаться.
3. Запустите его двойным щелчком.
4. Программа откроется в новом окне консоли.

> **Требования:** Windows 7/8/10/11, включённый Wi-Fi адаптер.

## Использование

### Главное меню
- **Utility** — переход в режим диагностики.
- **Cracker** — переход в режим симуляции аудита.
- **Settings** — настройки языка, звука, скорости, упрощенного режима, маскота, сброс сохраненных сетей, ссылки на YouTube и GitHub.
- **Exit** — выход.

Навигация: стрелки, мышь или клавиши `1`–`4`. Подтверждение — `Enter`. 
*Примечание:* Вы можете выделять мышью текст (через QuickEdit) и использовать `Ctrl+C` / `Ctrl+V` для копирования и вставки в строку ввода. Стрелки `←`/`→` и `Home`/`End` работают для редактирования текста.

### Консольные команды
В режиме консоли введите `/help` для получения списка всех команд (справка разбита на логические блоки, включая NETWORK INTERACTION).

**Основные команды:**
- `/select <wifi|номер>` — выбрать сеть.
- `/info` — базовая информация о сети.
- `/details` — расширенная техническая информация.
- `/all` — **МАКСИМУМ** информации о выбранной сети (глубокий анализ).
- `/sysnet` — посмотреть блокировщики ОС (Firewall, DNS, Proxy, VPN, Hosts).
- `/scan` — обновить список сетей (показывает `[+]` новые и `[-]` пропавшие).
- `/filter <текст>` — отфильтровать список сетей.
- `/channels` — визуализация загруженности каналов.
- `/stats` — статистика текущей сессии (время работы, сколько сетей взломано).
- `/reset <wifi|all>` — сбросить сохранённые ключи.
- `/volume <off|low|med|high>` — изменить громкость звуков.

**Диагностика:**
- `/interface` — статус вашего беспроводного адаптера.
- `/ping [хост]` — реальный ICMP-пинг (по умолчанию шлюз).
- `/arp` — реальная ARP-таблица.
- `/devices` — «сканировать» подключённые устройства (симуляция).
- `/sniff` — «перехватить» трафик (симуляция).
- `/probe` — «прощупать» роутер (симуляция).

**Симуляция взлома (режим Cracker):**
- `/run` — запустить атаку (PMKID, Deauth, WPS, CSA, KRACK, Evil Twin).
- `/abort` — прервать текущую атаку.
- `/keys` — показать все сохранённые пароли.
- `/errors` — **справочник ошибок**. Если атака встала, ищите здесь код ошибки.
- `/error <код>` — подробности конкретного кода.
- `/spoof` — сменить MAC-адрес (симуляция).
- *Команды исправления:* `/wait`, `/retry`, `/deauth`, `/downgrade`, `/rescan`, `/reroute`, `/replay`.

## Особенности интерфейса

- **Управление:** Полноценное редактирование строки ввода, история команд (стрелка вверх), переключение Tab (автодополнение команд и имен сетей).
- **Максимум информации:** Команда `/all` генерирует подробный отчет, включая MAC-рандомизацию, MIMO, время аптайма AP и сырые данные.
- **Проводные сети:** Кабели (Ethernet, Local Area Connection) отображаются внизу панели Wi-Fi. Если попытаться их выбрать, программа сообщит, что поддержка проводных сетей появится в будущих обновлениях.
- **Маскот AV:** Голубой пиксельный персонаж в правом нижнем углу консоли (и в меню, и в рабочих режимах).

## Как доработать (Для разработчиков)

Проект написан на Batch с внедрённым PowerShell-скриптом. Если вы хотите внести изменения, просто откройте файл `.bat` в редакторе (например, **Notepad++**, **VS Code**) и сохраните в **UTF-8**.

**Структура кода:**
1. **Обертка (`@echo off ... goto :eof`)** — запускает PowerShell с параметром Bypass.
2. **Состояние и настройки** — `Load-AppState` и блок `$script:i18n` (локализация).
3. **Интерфейс** — `Write-At`, `Draw-AVMascot`, `Render-Logs` (вся отрисовка).
4. **Логика** — `Process-Command`, `Scan-RealWiFi`, `Run-SysNetInfo`, `Show-AllNetworkDetails`.
5. **Цикл событий** — в самом низу (`while ($true)`) обрабатываются нажатия клавиш (WinAPI) и клики мыши.

**Как добавить свою команду:**
1. Найдите функцию `Process-Command`.
2. Внутри блока `switch ($verb)` добавьте новый кейс (например, `"mycmd"`).
3. Напишите логику: используйте `Add-Log "Текст"` для вывода и `Render-All` для обновления экрана.

**Сохранение прогресса:**
Данные хранятся в `%APPDATA%\AirView_alpha_v#.#.#_state.json`.

Все «атаки», «взломы» и «перехваты» являются **визуальной имитацией**. Программа не выполняет никаких реальных действий по взлому, не обходит защиту и не наносит ущерба. Реальные данные (SSID, BSSID, уровень сигнала, каналы, DNS, Firewall) считываются через стандартные средства Windows исключительно для отображения информации.
