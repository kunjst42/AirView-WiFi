# AirView alpha

**AirView alpha** — это стильная консольная программа для Windows, которая сочетает в себе реальную диагностику Wi-Fi сетей и визуальную имитацию хакерского аудита. Написанная на Batch с использованием PowerShell для отрисовки интерфейса, она предоставляет подробную информацию о беспроводных сетях, проверяет соединение и развлекает ретро-эстетикой.

> **Важно:** AirView alpha — **не настоящий хакерский инструмент**. Все процессы «взлома» являются визуальной симуляцией, созданной для демонстрации и развлечения. Программа не наносит вреда вашей системе или сетям.

---

##  Возможности

- **Два режима работы:**
  - **Utility (Диагностика)** — реальные данные о Wi-Fi сетях через `netsh wlan`, проверка `ping`, вывод ARP-таблицы, анализ каналов.
  - **Hacking (Симуляция)** — красочная имитация аудита безопасности с перехватом рукопожатий, подбором ключей WEP/WPA2/WPS и другими «хакерскими» сценариями.
- **Детальная информация о сетях:** SSID, BSSID, производитель (OUI), тип шифрования, WPS, RSSI, канал, частота, расстояние, задержка.
- **Ретро-интерфейс:** 8-битные звуки, пиксельный маскот AV, управление мышью и клавиатурой, прокрутка логов и списка сетей.
- **Мультиязычность:** английский, русский и китайский языки с корректным выравниванием текста.
- **Сохранение прогресса:** «взломанные» сети и настройки сохраняются в JSON-файл (`%APPDATA%\AirView_alpha_state.json`) и восстанавливаются при следующем запуске.
- **Экспорт отчёта:** команда `/export` сохраняет список сетей и их параметров в текстовый файл.

##  Установка и запуск

1. Скачайте файл `AirView_alpha.bat`.
2. Запустите его двойным щелчком (рекомендуется запуск от имени пользователя, не требующего прав администратора).
3. Программа откроется в новом окне консоли.

> **Требования:** Windows 7/8/10/11, включённый Wi-Fi адаптер (для получения реальных данных). PowerShell должен быть доступен (встроен в Windows).

##  Использование

### Главное меню
- **Utility** — переход в режим диагностики.
- **Hacking Tool** — переход в режим симуляции аудита.
- **Settings** — настройки языка, звука, скорости анимации, маскота и сброс сохранённых сетей.
- **Exit** — выход.

Навигация: стрелки, мышь или клавиши `1`–`4`. Подтверждение — `Enter`.

### Консольные команды
В режиме консоли введите `/help` для получения списка всех команд.

**Общие команды (доступны в обоих режимах):**
- `/select <wifi|номер>` — выбрать сеть для просмотра свойств.
- `/scan` — обновить список сетей (реальный скан адаптера).
- `/interface` — показать состояние беспроводного адаптера.
- `/ping [хост]` — выполнить реальный ICMP-пинг (по умолчанию шлюз).
- `/arp` — показать ARP-таблицу.
- `/channels` — визуализация загруженности каналов и безопасности.
- `/reset <wifi|all>` — сбросить сохранённые ключи для одной или всех сетей.
- `/settings` — открыть настройки.
- `/menu` — вернуться в главное меню.
- `/clear` — очистить лог.
- `/exit` — выход.

**Команды режима Hacking (симуляция):**
- `/run` — запустить имитацию подбора пароля для выбранной сети.
- `/devices` — «сканировать» подключённые устройства (симуляция).
- `/sniff` — «перехватить» трафик (симуляция).
- `/probe` — «прощупать» роутер (симуляция).
- `/keys` — показать все сохранённые «взломанные» ключи.
- `/spoof` — сменить MAC-адрес адаптера (симуляция).

##  Особенности интерфейса

- **Маскот AV** — голубой пиксельный персонаж в правом нижнем углу.
- **8-битные звуки** — ретро-эффекты при навигации и действиях.
- **Адаптивная вёрстка** — интерфейс подстраивается под размер окна консоли.
- **Прокрутка** — колесо мыши прокручивает лог или список сетей.
- **История команд** — стрелки вверх/вниз, а также клик по строке лога с командой (начинается с `>`) восстанавливает её в поле ввода.

## Как доработать (Для разработчиков)

Проект написан на Batch с внедрённым PowerShell-скриптом. Если вы хотите внести свои изменения, вам не нужно компилировать программу — достаточно открыть файл `.bat` в любом текстовом редакторе (например, **Notepad++**, **VS Code** или **Sublime Text**).

**Структура кода:**
1. **Обертка (`@echo off ... goto :eof`)** — запускает PowerShell и передает ему управление.
2. **Состояние и настройки** — блоки `Load-AppState` и `$script:i18n` (локализация).
3. **Интерфейс** — функции `Write-At`, `Draw-AVMascot`, `Render-Logs` и др.
4. **Логика** — обработка команд в `Process-Command`, сканирование Wi-Fi в `Scan-RealWiFi`.
5. **Цикл событий** — в самом низу (`while ($true)`) обрабатываются нажатия клавиш и клики мыши.

**Как добавить свою команду:**
1. Найдите функцию `Process-Command` (примерно в середине файла).
2. Внутри блока `switch ($verb)` добавьте новый кейс (например, `"mycmd"`).
3. Напишите логику: используйте `Add-Log "Текст"` для вывода в консоль и `Render-All` для обновления экрана.

**Как добавить новый язык:**
1. В блоке `$script:i18n` скопируйте словарь `"EN"` и назовите его, например, `"DE"`.
2. Переведите все значения.
3. В массиве `$langs = @("EN", "RU", "ZH")` (в функции `Trigger-SettingsOption`) добавьте `"DE"`.

**Отладка:**
Если программа вылетает, запустите её через PowerShell напрямую, чтобы увидеть текст ошибки. Для этого откройте PowerShell в папке с файлом и введите: `.\AirView_alpha.bat`.
